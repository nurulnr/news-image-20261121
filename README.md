A newspaper front page that sums up the world's news of Saturday 21 November 2026 in one image: Poland demanding NATO action after Russian missiles land on its soil, the AI-led market sell-off (S&P into correction, Nikkei down 5.1%) against Anthropic's $2 trillion Wall Street debut, Trump weighing new strikes on Iran, the ballistic missile strike on Kryvyi Rih, COP31 running past its deadline without a deal, and GTA 6's record $4.9bn first day.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

The program copies `entry.png` to `$MAKEFUN_OUTPUT_DIR/entry.png` (or `/output/entry.png` in the grader). It is deterministic: both runs write the same bytes, and it uses no network and no third-party packages. The image is 1024×1024 PNG, 117 KB.
